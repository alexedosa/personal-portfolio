PROJECT NAME: Daniel's Portfolio Website

LIVE LINK: https://alex-portfolio-tau.vercel.app/

DESCRIPTION:

A professional, responsive portfolio website built to showcase front-end development skills and projects. This site focuses on clean UI, accessibility, and high-performance code.

FEATURES:


Responsive Design: Fully functional on mobile, tablet, and desktop.

Semantic HTML: Built with SEO and accessibility best practices.

Custom Styling: Pure CSS3 layouts without external UI frameworks.

Interactive UI: Custom hover effects and smooth navigation.

TECHNOLOGIES USED:


HTML5

CSS3 (Flexbox and Grid)

Vercel (Deployment)



TECHNICAL DECISIONS:

I'll soon use a Mobile approach to ensure the site is lightweight on handheld devices. 

I chose CSS Grid for the main layout to maintain a clean structure and Flexbox for component alignment.

The code follows a clear naming convention to ensure it is easy to read and maintain for other developers.


HOW TO RUN LOCALLY:

Clone this repository.

Open the project folder.

Launch index.html in any modern web browser.
